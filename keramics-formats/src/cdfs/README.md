# cdfs

The cdfs module provides read-only support for the
[CD file system (cdfs)](https://keramics.github.io/cdfs.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format versions | ISO 9660 level 1, 2 and 3 |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| Extensions | Apple Hybrid CD, Joliet, Rock Ridge, El Torito, UDF |
| | Cross-Volume File Referencing |
