# Storage media image formats

A storage media image format is used to store data from storage media devices such as a hard disk,
a floppy or optical disk like CD-ROM or DVD.

* [Parallels Disk Image (PDI)](pdi.md)
* [QEMU Copy-On-Write (QCOW)](qcow.md)

* [Virtual Disk Image (VDI)](vdi.md)
